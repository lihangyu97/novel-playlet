# novel-playlet

一个 **小说 / 短剧聚合阅读器**：内容实时来自第三方公开接口，App 自身不存任何内容。
Flutter 写 UI，Rust 内核负责签名、设备池、请求与解密。iOS 优先（自签真机可用），Android 打包链路已打通。

> 内容版权归原作者所有，本项目仅供学习研究，使用后果自负。

## 能做什么

- **推荐**：搜索 + 分类 tabs（小说 / 短剧 / 漫剧），各分类独立推荐流（白底不定高卡片 + 瀑布流，默认双列、设置可切三列；封面按内容域原生比例），翻页、下拉刷新、首屏自动补页。
- **搜索**：推荐页顶栏右侧搜索图标进入独立搜索页，一次同时搜小说 / 短剧（两行横向卡片，漫剧混在短剧行）；空输入时展示搜索历史 + 热搜榜（最多 30 条，前三名名次标红，词条后带 `display_tag` 彩色角标，热度保留接口前缀并显示为整数 `3905w+`，点词直接搜）。
- **排行榜**：推荐页小说 / 短剧 / 漫剧三个 tab 的瀑布流上方各有一个榜单区块（榜名在卡片外面 + 一行与搜索结果同款的前十卡片，可左右滑 + 「更多」）；点「更多」进排行榜页，二级 tab 横滑/左右滑并自动定位到来源榜，列表展示名次、封面、评分、作者/分类/热度、简介和题材标签，支持触底翻页。
- **小说**：详情 / 目录 / 书架；详情页书评卡片（首条 + 弹窗看全部，书评配图渲染缩略图）；阅读页真实分页、左右翻页、人物对话高亮（成对引号内的说话内容描色，跨段对话也识别；样式可选荧光笔 / 下划线 / 波浪线 / 文本，文本样式直接把命中文字染成所选颜色，颜色在设置-主题里自定义，阅读设置可关）、段评气泡、工具栏「评论」/评论面板（只读，评论/回复配图渲染缩略图、方括号表情渲染官方图片，点击全屏可双指缩放、点任意处立即关闭）、顶部左侧书名（与右侧动作同字号，超宽省略）+ 右侧「加入书架→已在书架（只读，只加不移）/ 缓存小说→缓存中→已缓存（缓存中、已缓存点进缓存中心）」两个文本动作、日间/夜间切换（日间回上次选的浅色纸）、字号行距/字重与 4 种底色、自定义背景图（作为第五种底色，45% 纸色遮罩，夜间自动隐藏）、目录跳章、邻章预取、进度续读。
- **短剧**：详情（剧评 + 选集 + 收藏/缓存）/ 播放；播放页上下滑切换集数（竖向翻页，无上一集/下一集按钮）、播完自动下一集、播放中保持屏幕常亮、1.0–3.0x 倍速（点倍速文字弹小浮窗，不再遮大半屏）、横屏全屏（底栏倍速左边显示时间 / 电量 / 当前网络），在线边下边播、已缓存集切集秒开；底栏暂停键两侧是当前集号（选集）/ 详情 / 评论 / 相关 和清晰度 / 倍速，除播放键外全部是纯文字（收藏、缓存收进「详情」弹层，收藏只加不移，与阅读页加入书架一致；历史最近观看直进播放页也能操作），顶栏只留返回 + 剧名。
- **离线**：整本小说 / 整剧短剧一键下载，断网可读可看；下载进度、网速、排队、暂停/续传集中在「我的 → 缓存」。
- **我的**：统一页头 +「在看」「收藏」「历史」三个小说/短剧混排区块（类型标签区分）。阅读页 / 播放页悬浮 pin 按钮可把当前内容加入「在看」，再看一次取消；「在看」一排卡片横向滑动（只显示标题与读到第几章/看到第几集），区块头「全部 ›」打开全量列表；收藏最多预览 6 个（手机 3 列正好两排），历史预览 3 条。各区块标题右侧显示总条数 +「全部 ›」，弹窗列表可左滑删除（在看只取消 pin、历史只清进度、收藏走移出收藏，均二次确认），删除后自动推一次 WebDAV 同步。
- **设置**：主题色（天蓝 / 草绿 / 绯红 + 自定义取色；自定义圆点显示上次所选颜色）、对话高亮（点圆形色块开弹层：荧光笔 / 下划线 / 波浪线 / 文本样式 + HSV 取色，示例正文按当前样式与颜色实时预览）、深色模式（跟随系统或手动）、推荐流布局（双列 / 三列按钮组，默认双列）、全局字重（仅 Android；阅读器默认跟随，可在阅读器内覆盖）、WebDAV 云同步（书架/收藏/进度 + 主题/阅读排版等设置，应用密码进 Keychain/Keystore）、存储（占用明细 + 右下角图标式清理，卡片内注明不含主动缓存的小说/短剧）与下载清晰度（四档按钮组，跟存储同区）、诊断（「运行日志」记录接口报错与不符合预期的事件，只存本机，最近 300 条）。

## 架构

```
Flutter UI → Riverpod → ApiClient → BackendTransport
                                        │ flutter_rust_bridge（进程内 FFI）
                                        ▼
                          Rust 内核（签名/设备池/请求/重试/解密）
                             │ HTTPS                    │ 回环 127.0.0.1
                             ▼                          ▼
                          上游接口              /src 视频按 Range 解密 → 播放器
```

签名、设备池、限流、重试、正文解密、CENC 解密全部在 Rust；Dart 只传请求参数和渲染 UI。
详细的请求链路、两条内容链路（缓存 → 分页/播放 → 渲染）、缓存布局与构建说明见
[docs/implementation.md](docs/implementation.md)。

## 构建与运行

环境：Flutter 3.47.9、Rust 1.99.1、Xcode 27+、CocoaPods 1.17；Android 另需 JDK 17、SDK 36、NDK 28.2.13676358。
`flutter_rust_bridge` 两端必须同为 2.13.0。

iOS：

```bash
flutter pub get
pod install
./scripts/build_ios_app.sh --flavor release   # release 包（建议在 main 上跑）
./scripts/build_ios_app.sh --flavor beta      # beta 包（可同时安装，数据独立）
# 产物 output/ipa/novel_playlet_<flavor>_<sha>_unsigned.ipa
```

Android：

```bash
./scripts/build_android_app.sh --flavor release   # 正式包
./scripts/build_android_app.sh --flavor beta      # beta 包（独立 applicationId，可共存）
# 产物 output/apk/novel_playlet_<flavor>_<sha>.apk
```

两个脚本都会先编 Rust 内核，`--skip-rust` 可跳过。`output/` 已在 `.gitignore` 里，
构建交付物不入库。iOS 的 IPA 是未签名的，签名/安装见
[docs/implementation.md](docs/implementation.md) §7；Android 加了渠道后，
直接 `flutter run` / `flutter build apk` 要带 `--flavor prod|beta`。

App 显示名「摆烂盒子」，Bundle ID `com.lihangyu.novelPlaylet`。免费 Apple ID 自签 7 天有效，
真机安装与签名细节见 [docs/implementation.md](docs/implementation.md) §7。

## 已知限制

- 首次打开必须联网完成设备注册；短剧起播需要先整集下载进内核缓存（流式起播未做），在线清晰度不可选（默认 720P，没有 720P 时取最高可解码档）。
- 离线下载仅前台、单任务、无字节级断点；离线内容明文落盘。
- 不做听书 / 漫画 / 弹幕 / 画中画 / 后台播放 / AirPlay / 锁屏控制；视频进度只记到「集」。
- 段评/书评/短剧剧评**只读**：不支持发评论、点赞、回复；短剧「本集评论」按官方热评列表 cursor 翻页（20 条/页）；纯文本源没有段落锚点时不显示气泡。
  升级前缓存/下载的章节缺段落锚点，气泡开启时会自动补取一次带锚点的正文（断网时保留原文）。
- iOS 长时间挂起可能回收本机回环监听（Apple TN2277，表现为播放必现 -1004、杀进程才恢复）：内核同端口自愈重绑，播放页对 -1004 只做一次有界恢复，仍失败才提示重启 App（见 docs/implementation.md §3.2、§5.7）。
- 播放页倍速在操作行最右；横屏视频的全屏入口是画面下方「全屏观看」（全屏时隐藏）。阅读器默认字号 21、行距 1.8、字重 400；阅读器工具栏不再放上一章/下一章（点正文左右分区、章边界继续滑动、目录都能切章）。
- Android 播放运行时仍待真机全面验证；iOS 上架需处理 GPLv3 与内容授权，当前定位自用 / 自签。
